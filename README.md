# Five Hundred Nights — 500 bedtime stories in English

Original bedtime stories for children (ages 4–8), made for YouTube.

Each story is a **16:9** film, **5 minutes or longer**, narrated in English by Luna.

This set is a new collection of **500** stories. It does not repeat the earlier packs:

- [inodeman/100-bedtime-stories](https://github.com/inodeman/100-bedtime-stories)
- [inodeman/300-bedtime-stories](https://github.com/inodeman/300-bedtime-stories)

## What’s in each folder

`stories/NNN-slug/`

| File | What it is |
|---|---|
| `video.mp4` | YouTube widescreen film (picture-book scenes + narration) |
| `audio.mp3` | Narration only |
| `title.txt` | YouTube title |
| `description.txt` | Description with hashtags |
| `youtube.txt` | Title and description together, ready to paste |
| `story.txt` | Full story text |
| `meta.json` | Duration, moral, theme |

Channel series by InodeAi. Five hundred kind nights, one story at a time.
